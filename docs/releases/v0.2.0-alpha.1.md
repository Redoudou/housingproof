# v0.2.0-alpha.1 — Working synthetic proof MVP

Housingproof now answers the two approved questions with genuine UltraPlonk proofs over signed synthetic RPIE projections.

## Included

- Q001: reported regulated units ≥ 20, with YES and NO proofs.
- Q002: calculated reported operating balance declined by more than 20%, including exact-boundary and negative-current cases.
- Shared fixed-order salted Poseidon2 commitment, complete range checks, source/period binding and locally pinned circuit/VK fingerprints.
- Isolated proof workers, timeouts, one active request, and no answer on failures.
- Refreshed local demo: registration, question selection, verified answer, public bundle export/import and changed-answer rejection.
- Standalone verification without dataset or issuer private key.
- Real proof, constraint, tamper and browser tests; in-memory simulated disclosure log.

## Run

```bash
npm ci
npm run zk:build
npm run dev
```

Open http://localhost:3000. Register a 2025 source and ask Q001. For Q002, register a comparable 2024 source too. Export the answer and verify with an independently obtained issuer public key:

```bash
npm run verify -- answer-bundle.json trusted-issuer-public.pem
```

The first build requires internet for public CRS initialization. Old bundle-2 receipts are not accepted; re-register after upgrade. See [protocol](../proof-protocol.md) and [validation report](../mvp-validation.md).

## Scope

Synthetic records and simulated issuance only. No production authentication, persistence of registrations/disclosure logs, source revocation or City integration. Circuits and application are not independently audited. The static Pages site remains a project overview; live proving runs in the local Node service. A proof checks computation against reported values, not an owner's accuracy or legal entitlement.
