# v0.1.0-alpha.1, Synthetic prototype foundation

Housingproof explores verified answers from confidential RPIE filings without sharing the underlying record.

This first prerelease establishes the dataset, local simulation, and implementation plan. **It is not a working zero-knowledge proof release.**

## Included

- Source-mapped residential RPIE subset with integer USD cents and explicit validation limits.
- Synthetic 2024/2025 data for one fictional 40-apartment property, with boundary and failure cases.
- Fixed Q001 definition and Q002 specification/fixture calculations.
- Local Express custodian service, signed simulator source receipts, and agency interface.
- Private registration salts; input validation before issuance; fixed-threshold policy checks.
- Verification boundaries that refuse signature-only claims and withhold unverified answers.
- MVP plan, implementation review, tests, CI, and project presentation.

## Known limits

- Genuine ZK proving and independent proof verification are not implemented.
- The legacy circuit is disabled; it does not match the current source commitment.
- The standalone verifier exits unsuccessfully until real proof verification is implemented.
- The local service illustrates roles, not production isolation or authorization.
- The project site is an overview, not a running custodian/prover service.
- All data and issuance are synthetic. No real City integration is included.

## Run

Node.js 22+ and Python 3:

```bash
npm ci
npm run check
npm test
npm run dev
```

Open http://localhost:3000. Register a synthetic source and inspect its receipt. Asking the fixed question currently reports proof generation as unavailable.
